# Cursor plugins

Cursor 側で有効にしているプラグイン。セットアップスクリプトは一覧を表示するだけで、インストールは Cursor の Plugins から行う。

| Plugin | 用途 |
| --- | --- |
| [1Password](https://github.com/1Password/cursor-plugin) | シークレット管理 / MCP |
| [Railway](https://github.com/railwayapp/railway-skills) | デプロイ・インフラ操作 |
| [Vercel](https://github.com/vercel/vercel-plugin) | Web アプリのビルド・デプロイ |
| [PR Review Canvas](https://github.com/cursor/plugins/tree/main/pr-review-canvas) | PR diff を Canvas でレビュー |
| [Docs Canvas](https://github.com/cursor/plugins/tree/main/docs-canvas) | ドキュメントを Canvas で表示 |
| [Modern Web Guidance](https://github.com/googlechrome/modern-web-guidance) | 現行 Web プラットフォームの案内 |

認証トークンや MCP の OAuth キャッシュはリポジトリに含めない。
